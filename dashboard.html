🎓 NetQuiz – PBL Project Concept & Viva Guide

1. Project Abstract

NetQuiz is a web-based educational assessment application engineered to facilitate student learning of Computer Networks concepts. The application provides structured multiple-choice questions across six vital domains (OSI/TCP-IP, Subnetting, Transport Layer, Topologies, Routing/DNS, and Security) with an automated 10-minute timer, instant scoring, LocalStorage persistence, and client-side architectural demonstrations.

2. Networking Architecture Explained

  • Client-Server Model: The browser acts as the client requesting resources (HTML/CSS/JS) from a web server via HTTP over port 80/443.
  • TCP Transport (RFC 793): Ensures reliable packet delivery using sequence numbers, acknowledgments, sliding windows, and 3-way handshakes.
  • IP Addressing (Layer 3): Logical addressing (IPv4/IPv6) enables packets to be routed across distinct subnets and gateways.
  • DNS Resolution (Layer 7): Maps domain names (e.g. netquiz.edu) to server IP addresses via hierarchical DNS lookups.

3. Architecture Truth & Prototype Label

Academic Integrity Note: The standard version runs completely inside the browser using HTML5, CSS3, JavaScript, and LocalStorage for client-side persistence. It does not run a multi-tenant backend server or peer-to-peer multiplayer network; it is designated as a Client-Side Prototype suitable for Live Server execution.
